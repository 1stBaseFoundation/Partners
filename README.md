# Partners

Custom scripts for developers/partners/exchanges to manage wallets and transactions.

1. **sample_wallet.php**
PHP Script to generate new wallets on a local node, with optional arguments to return pubKey, privKey and wordphrase.

2. **sample_wallet.php**
PHP Script to generate transactions on a local node, fetches UTXOs, signs transactions and returns txhash before submitting to the mempool for mining.
